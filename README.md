# Daybreak Coffee

A responsive café landing page for **Daybreak Coffee**, designed to showcase the brand, menu highlights, and café locations.

## Features

- Responsive layout with mobile navigation
- Café story, menu highlights, and location sections
- Scroll-triggered reveal effects and a reading progress indicator
- Parallax-style hero image movement
- Keyboard-accessible navigation, skip link, and reduced-motion support
- Automatically updated copyright year

## Project files

- `index.html` — page content and structure
- `styles.css` — layout, responsive styling, and visual effects
- `script.js` — navigation and scroll interactions

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve the project directory with a local static server. For example, with Python installed:

```powershell
py -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## External resources

The page loads fonts from Google Fonts and café photography from Unsplash. Those resources require an internet connection; the page's local HTML, CSS, and JavaScript are otherwise self-contained.
